# PROJECT_CONTEXT

## 产品目标

帧印 FrameMark 是本地桌面随机单帧视频版权水印工具。每个连续时间区间选择一个真实视频帧，
在安全区域内放置自由文字水印，增加寻找和清理全部身份标记的工作量。

## 当前版本

- 1.1.2 开发预发布，Windows 10/11 x64；官网稳定版仍为 1.1.1。沿用对应源码完整可获取的自建 FFmpeg。
- macOS 保留架构兼容性，未构建和验证。
- 自有源码、文档与品牌图标 MIT；第三方组件保留各自许可。

## 架构和规则

- Tauri 2 + TypeScript/HTML/CSS + Rust；SQLite 位于应用数据目录。
- 随包 FFmpeg/ffprobe 为固定官方 7.1.1 源码及 8 项明确输入的自建 GPL-3.0-or-later 构建，版本/哈希见 `docs/compliance/ffmpeg-selfbuild/binaries.json`，构建脚本和全部对应源码随 Release 提供。旧 Gyan 安装包保留作历史比对，不公开补发。
- 按真实帧 PTS 保留原区间选帧算法；末尾不完整区间也选一帧。
- 算法 V2 先生成完整多水印计划，再执行 FFmpeg 流式合成；相同帧列表、配置、字体/工具版本和 Seed 可复现。
- 每条文字通过实际 FFmpeg 光栅测量确定包含描边/背景余量的矩形。
  支持换行、最多缩小基础字号 25% 和有限随机碰撞重试，仍无法容纳则编码前明确失败。
- 预览用同一计划与 FFmpeg 绘制函数生成首帧 PNG，不使用浏览器字体估算替代输出规则。
- 同文字的不同水印仍按独立选择槽绘制；随机字号按基础值附近三个档位变化。
- H.264 编码自动优先 NVENC → QSV → AMF → CPU；以实际最小编码测试判断可用性，硬件失败清理部分输出后重试 CPU。
- Windows Release 为 GUI subsystem；所有 FFmpeg/ffprobe 使用无控制台子进程，保留管道进度和错误。

## 已实现功能

- 自由水印信息：新增、编辑、复制、删除、上下排序；每条最多 240 字符、8 行，无平台必填项。
- 多选和本次独立排序；同时出现模式每个事件显示全部水印，依次闪现模式按顺序循环。
- 处理前摘要区分事件数与绘制数；短视频无法轮到全部水印时提示。
- 样式预览、重新随机、依次切换、安全区域辅助框。
- Schema user_version=1 原地迁移：保留旧 identities 表及文字、enabled、ID，新增 sort_order；
  histories 新增 plan_json。旧历史继续读取原明细，新历史记录完整计划、选择文字快照、顺序、配置和算法版本。
- 删除保存的水印不删除历史快照；保存的选择顺序存在设置 JSON，不修改旧库的其他设置。
- 点击/拖拽视频、媒体信息、HDR 提示、进度、取消、输出校验、原视频不覆盖、日志和历史定位。
- 兼容音频流复制，其余转 AAC；文本字幕转 mov_text，无法处理的字幕明确失败；元数据与章节保留。
- NSIS 安装根目录提供 frame-mark.exe 和“帧印”快捷方式，开始菜单保留入口；
  应用、安装包和快捷方式使用同一品牌图标，WebView2 Bootstrapper 内嵌安装。

## 限制与剩余发布事项

- 1.1.2 完成弹窗支持 × 和原生 Esc 关闭；默认 README 为中文。
- 1.1.2 NSIS 仅简体中文，机器级新装默认 `$PROGRAMFILES64\framemark`；沿用机器级旧目录和用户指定路径。
  旧 per-user 安装会提示先卸载且保留数据，暂不自动跨权限迁移。
  当前后台非管理员会话不能完成 UAC/机器级安装验收，未替换官网稳定下载。

- 输出固定 H.264 MP4；H.265 仅输入。HDR/Dolby Vision 色彩不保证保持；数据/附件流不复制。
- CPU 仍负责文字滤镜；本机已验证 NVIDIA，QSV/AMF 需要对应硬件测试。
- 不包括剪辑、AI、联网账户、Logo、自动避脸或避字幕。
- WebView2 Runtime 缺失时，Bootstrapper 需要联网获取 Runtime；视频处理不联网。
- 1.1.1 对应源码包包含全部 8 项固定源码输入、构建脚本、配置、许可证和匹配二进制；完整解包逐项哈希验证通过。GitHub Release 提供长期匿名获取方式。
- 旧 1.1.0 的 Gyan 材料缺口已通过替换构建解决，不补发旧安装包。`npm run audit:ffmpeg` 仍是旧 1.1.0 历史审计，默认返回其历史阻塞状态，不是 1.1.1 发行检查入口。
- 1.1.1 安装包无 Authenticode 签名，Windows/SmartScreen 可能提示未知发布者。
